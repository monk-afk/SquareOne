# Recent Updates

### Apr 26 | Chat Channels {.header-separator}

Some changes are being made to how players can communicate in-game.

The chat command `/chat` now serves more purpose than disabling chat messages.

**Chat channels**

- `/chat ?` **lists open populated channels**

- `/chat ? [channel]` will **list the players in the specified channel**

- `/chat main` return to Main chat (Default Public)

- `/chat [channel]` **to join a side channel**.

If the side channel does not exist, it will be created when using the command.

Side-channel messages are not censored. However, **rules still apply** and **Staff can monitor all channels** at the same time and messages are still broadcast to Discord `#🎮｜ingame-chat`. Inappropriate channels will be removed.
